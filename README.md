# Academia Management System

A Java Swing-based university management system implementing Object-Oriented Programming concepts and GUI design.

## Features
- Student Management
- Professor & TA Management
- Course Management
- Scheduling System
- Search & Filtering
- Dashboard Analytics
- Timetable Visualization
- Java Swing GUI

## OOP Concepts Implemented
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Generics
- Arrays
- Error Handling

## Technologies Used
- Java
- Swing GUI
- OOP Principles

## Project Structure

src/
└── management/
    └── AcademiaApp.java

## How to Run
1. Open Eclipse
2. Import project
3. Run AcademiaApp.java
